# Dataset folder

`wafer_samples.csv` is a **synthetic demonstration dataset** created for testing the Java Swing workflow. It contains 108 17×17 maps: 12 each for Center, Donut, Edge-Loc, Edge-Ring, Loc, Near-Full, Random, Scratch and None.

Grid encoding: `0` = pass/good die, `1` = fail/defective die, `E` = edge/outside wafer. Rows within each map are separated by `|`.

This is not the original WM-811K dataset. Replace/add the genuine WM-811K source data only after obtaining it from the source cited in the project documentation and verifying its schema. Keep provenance and license information with any imported real dataset.
